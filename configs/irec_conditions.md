# IREC 회수 영상 조건 (가정/설정값)

근거 문서: `sources/00_CURRENT_STATE.md`, 개발 공통 규칙 §1·§2·§3.
이 문서의 값은 **실측이 아니라 합성 파이프라인용 가정/설정값**이다. 확정 임무
요구조건이 아니며, 팀 승인 요구조건으로 승격하지 않는다. 실제 카메라 보정·촬영
거리·대기 조건이 측정되면 그 값으로 대체한다.

## 1. 대회 환경 (가정)
- 장소: Spaceport America, New Mexico (사막 고지대). 대회 시기 6월.
- 배경: 정오 무렵의 진한 파란 하늘, 성긴 권운, 지평선 근처로 갈수록 옅어짐.
  낮은 고도/팬 촬영 시 황갈색 사막 지형(토양·관목)이 화면 하단에 들어올 수 있음.
- 조명: 강한 정오 태양. 캐노피 상단 하이라이트·하단 그림자, 백라이트 시 반투과로
  캐노피가 밝아짐.

## 2. 촬영 (가정)
- 지상 망원 렌즈 또는 드론 추적. 표적(낙하산)은 화면의 약 3~25%를 차지.
- 원거리 회수에서는 표적이 작고, 열 아지랑이(heat shimmer)·오토포커스 헌팅·
  손떨림이 겹쳐 추적이 어려움.
- 센서/코덱: 노이즈, 모션블러, 압축(JPEG/H.264) 블록 아티팩트.

## 3. 낙하 동역학 (가정)
- drogue(고속) → main(저속)으로 순차 전개. (기존 시퀀스 개념과 정합)
- 진자 흔들림(pendulum swing), 캐노피 자전, 바람에 의한 수평 표류.

## 4. 합성 파이프라인 반영 (구현)
`src/vision/scene.py`의 `RealismConfig` + `src/vision/synth.py`의 동역학 필드로
반영한다. `enabled=False`(기본)이면 기존 회색-하늘 경로가 그대로 쓰여 **기존
시나리오·테스트 동작이 보존**된다.

| 조건 | 파라미터 | 기본 IREC 프리셋(`irec_realism()`) |
|---|---|---|
| 파란 하늘 그라디언트 | `sky_top`,`sky_horizon` | (150,95,45)→(205,180,150) BGR |
| 권운 | `clouds` | 0.22 |
| 사막 지형 밴드 | `terrain_frac` | 0 (일부 시나리오 0.18) |
| 방향성 조명 | `sun_dir_deg`,`sun_intensity` | 60°, 0.35 |
| 백라이트 반투과 | `backlight` | 0.18 |
| 열 아지랑이 | `heat_shimmer` | 0.6 (원거리 1.1) |
| 센서 노이즈 | `sensor_noise`,`shot_noise` | 5.0, 0.03 |
| 압축 아티팩트 | `jpeg_quality` | 85 (원거리 72) |
| 진자 흔들림 | `swing_amp_px`,`swing_period_frames` | 표적별 |
| 자전 | `rotate_deg_per_frame` | 표적별 |
| 바람 표류 | `wind_drift_px` | 표적별 |

또한 toroidal main의 spill hole은 더 이상 검은 반점이 아니라 **뒤의 하늘색**으로
칠해진다(`hole_color`), 실제 "구멍으로 하늘이 보이는" 형상에 맞춘 것.

## 5. 추적 판정 기준 (가정)
개선 효과를 정량화하기 위해, 각 프레임의 **표적 유효폭 ≥ 8px** 이고 **표적/국소
배경 Michelson 대비 ≥ 0.12** 이면 그 프레임을 `trackable`로 본다. 생성물 메타
(`*_meta.json`)의 `trackability` 항목에 프레임 비율·평균 대비·평균 폭을 기록한다.
이 임계값은 가정치이며, 실제 검출기 성능을 보장하지 않는다(공통 규칙 §1).
